# 🍎 Fruit Mart - Cửa Hàng Trái Cây Tươi

Website giới thiệu và bán trái cây sạch, được tối ưu hóa giao diện cho cả máy tính và điện thoại (Responsive Design).
Fruit Mart là một dự án giao diện Web Front-end hiện đại, được xây dựng với mục tiêu tối ưu hóa trải nghiệm mua sắm nông sản sạch trên mọi nền tảng thiết bị. Dự án tập trung vào tính khả dụng, tốc độ phản hồi và giao diện người dùng (UI) tinh tế.

## ✨ Tính năng nổi bật
- **Giao diện di động**: Tự động chuyển đổi bố cục 1 hoặc 2 cột trên điện thoại.
- **Phong cách tối giản**: Thiết kế scholarly, tập trung vào hình ảnh sản phẩm.
- **Tốc độ tải nhanh**: Sử dụng hình ảnh tối ưu từ CDN Pexels.
- **Trang liên hệ**: Tích hợp form liên hệ và bản đồ địa chỉ.

### Các phân đoạn chính:
- **Navigation**: Thanh điều hướng thông minh, cố định khi cuộn trang.
- **Hero Section**: Khu vực biểu ngữ thu hút sự chú ý với nút kêu gọi hành động (CTA).
- **Product Grid**: Hệ thống hiển thị sản phẩm dạng lưới đa cột.
- **Contact Form**: Form liên hệ tích hợp chuẩn xác.
